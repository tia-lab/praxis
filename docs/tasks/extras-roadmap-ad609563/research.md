## 1. Nature of this folder

This is a **sequencing roadmap** over five independent units, written so an engineer
implements them one at a time in the order given. It is NOT a single-task G3 plan: each
unit in `PLAN.md` carries its own goal, scope, acceptance and boundary, and each still
needs its own **G0 ledger GO** (and its own G1/G2 where not waivable) before any G4 code.
This folder authorizes the order and shape only; it authorizes no code by itself.

Per-unit research belongs in each unit's own `docs/<slug>-<hash8>/` folder at dispatch.
The current built surface this roadmap extends is recorded in `STATUS.md` and
`docs/vision.md §13a` (2026-10-30 reconciliation): molecule core through P6 shipped, P7
experience the deepest layer, P4 closed at the current adapter set, P1 trusted identity
(gate #3) and gates #1/#4/#6/#7/#8 open.
